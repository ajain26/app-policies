1. What InkSign does

InkSign lets you import, scan or receive a document, place a signature, initials, text, a date or a check mark on it, and export, share, save or print the result. 4. The signing certificate

A signing certificate adds a page recording when a document was signed and a fingerprint of the file. It is an integrity check, not a cryptographic signature: the fingerprint uses no secret key, so anyone who edits the file can add a new certificate that matches the edited file. It is not a qualified or advanced electronic signature, it does not prove who signed, and it does not stop anyone from changing the file. Opening the file in InkSign shows whether it still matches the fingerprint in its certificate.
